# Image Processing Studio

A full-featured Image Processing application built with Python & OpenCV, 
featuring an interactive Streamlit GUI.

## Features
- Point Operations (Addition, Subtraction, Division, Complement)
- Color Image Operations
- Histogram Stretching & Equalization
- Spatial Filters (Average, Median, Max, Min, Mode, Laplacian)
- Image Segmentation (Global, Otsu, Adaptive Thresholding)
- Edge Detection (Sobel)
- Mathematical Morphology (Dilation, Erosion, Opening, Boundaries)
- Image Restoration (Salt & Pepper, Gaussian Noise, Outlier Method, Averaging)

## Tech Stack
Python · OpenCV · NumPy · SciPy · Streamlit · Matplotlib

## How to Run

### 1. Install dependencies
pip install -r requirements.txt

### 2. Run the app
streamlit run app.py
